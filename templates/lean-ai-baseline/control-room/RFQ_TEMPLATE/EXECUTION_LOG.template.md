# RFQ-XXX Execution Log

## Mandatory Reuse Audit

Before implementation, record:

- existing current/stable capability inspected;
- existing config/adapters/migrations/tests/scripts/packaging that will be reused;
- prior decisions/evidence reused instead of rediscovered;
- any capability that cannot be reused, with concrete incompatibility evidence;
- minimum new code required.

If an existing capability satisfies the need, reimplementation is prohibited.

## Execution entries

Append concise technical facts:
- implementation decisions;
- changed files and Git diff/commit range;
- exact tests/results;
- evidence references;
- true blockers;
- consolidation/removal of any temporary or duplicate path introduced during discovery.

Do not store secrets or raw terminal noise.
