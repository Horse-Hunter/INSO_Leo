# 答复模板

本文件由 CEO 维护，只定义通用答复格式；不记录任何项目当前进度或交接内容。默认简洁，先说结论，再说需要 Owner 做什么。

## Main Programmer → CEO

```text
状态：
DONE / BLOCKED

结果：
<一句话>

需要决定：
NONE / 一个明确决定

验证：
<关键测试>

阻塞：
NONE / 真正阻塞项

Commit：
<hash>
```

## CEO → Owner

```text
结论：
<一句话>

你要做什么：
NONE / 一个明确动作

需要决定：
NONE / 一个明确决定

下一步：
<一句话>
```

## 规则

- 没有内容就写 `NONE`。
- 不先贴技术日志。
- 不重复背景。
- 一个答复尽量只要求 Owner 做一个动作。
