# Workflow — active scheduling, safety and persistence

**Owner:** `src/workflow/`; launcher wires original Inquiry, Quotation, TP, independent mail and notifications. One scheduler/SQLite/outbox, not parallel replacements.

- Automatic inquiry: current source status `未发`, exact identity/complete source date and **last 7 Shanghai calendar days inclusive**. Automatic quotation: only `发给采购 / 采购已报价 / 已报价给客户` plus same 7-day rule and guards. Automatic TP: **last calendar month**, one original durable requirement task. Owner-selected manual single order may waive **age only**, never source status/identity/write-effect safeguards.
- Inquiry/quote/TP each use own original 900-second cadence. Full program `开始运行` schedules **all** modules, not just one row; `ProductionBackend(inquiry_ids=...)` only restricts inquiry, not quotation/TP/mail. No full auto Start masquerading as one-order test.
- Original INSO procurement and Google status update may succeed independently. Preserve distinct `SAVED / STATUS_WRITE_PENDING / SUBMIT_UNCONFIRMED / UNKNOWN`; replay is never a solution to missing acknowledgement. Current Google source state is separate from immutable procurement history.
- Quotation: original bound row, 14 RAW input cells, original CDP quote button and native result parsing; confirm real effect. Unknown input write/quote click remains durable `effect_uncertain`/hold across restart, status edits and manual retry; do not auto-close.
- Persistent SQLite stores inquiry/purchase/quote/TP state and one SMTP notification ledger with recipient `SENT / UNKNOWN / SUPPRESSED`; no duplicate messages. Verified current important-order/purchase-follow-up notices may wait up to original 120s for full six-source report, then use truthful bounded fallback; never fabricate quote, stock or amount.
- The Owner 2026-11-13 explicitly **removed pre-click 14-cell readback** but retained native result, cloud-write receipt, identity and unknown-effect holds. Transient Google **read** trouble must not create fake global failure/alert.
- Keep manual single-order action through existing state machine; verify it cannot concurrently trigger other orders. An interrupted agent session is not evidence of stopped Windows worker. Check actual original process, SQLite and external status before continuing.
