# INC-20261120 — 外部页面被当成"归属丢失"导致全局停机（14:29:45，已修）

**结论：`DEFECT_CONFIRMED_AND_FIXED / INSTALLED_RUNNING / ONE_ROW_KEPT_HUMAN_BY_DESIGN`。**

- **真实缺陷：** 程序在扫描共享 Chrome 的标签页时，把**不是自己创建的页面**（Owner 手动开的、或别的模块开的、没有租约的页面）当成"页面归属丢失"，抛出 `CDP_PAGE_OWNERSHIP_UNCONFIRMED`，然后按全局安全停下**全部业务**。这类页面在共享 Chrome 里很正常，不该停机。
- **证据：** 界面 `ValueError(NATIVE_PAGE_LEASE_MISSING)`；日志 `14:29:07 quotation phase=failed` → `14:29:09 runtime fault reason=CDP_PAGE_OWNERSHIP_UNCONFIRMED`；当天日志里 `workflow step failed` 只有一条通用行，说明失败发生在"扫描/收口"这条边，而不是某个 Google 步骤。
- **不是：** 不是 CDP 断开（`/json/version` 正常、14 个 target）、不是表格不可达（同一时刻 API 读取正常）、不是写入不确定（写意图全 `SETTLED`）。

## 1. 修复

- `src/research/cdp_pages.py`：新增 `page_is_owned(page)`（非抛异常判定）；`native_page_owner()` 在缺租约时会打一条**自有点位名**的日志（`lease-missing-<调用点>`），让下次同类问题一眼定位，不再只给一个错误码。
- `src/launcher/google_quote_update.py`：
  - 扫描 Chrome 标签页时（错误页收口分支）先判 `page_is_owned`，不是自己的一律跳过；
  - `close()` 遇到 about:blank / chrome-error 且无租约的页面：**不关闭、不抛错**（无法证明是我们的，就不动它）；
  - `_require_owned_page()`：无租约 = "不是我们的"，**纯读**改为 `GoogleReadTargetUnavailable`（本轮重建自己的页面后继续），**写**仍然失败关闭（`GOOGLE_TAB_IDENTITY_UNCONFIRMED`）。
- 语义边界没动：身份不匹配（targetId 不同）、真实写入不确定、hold、`UNKNOWN/SENT` 一律照旧失败关闭。
